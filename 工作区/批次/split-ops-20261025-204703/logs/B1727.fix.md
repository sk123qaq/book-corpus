## 根因（两件事，都不是哪一章被截断）

逐文档把源 EPUB 的 73 个 xhtml 按 audit 的口径（字母数字+CJK）计数，与每个 md 对齐：24 个
TOC 章节文件的三方读数全部吻合（md ≈ 源文档字数 + 章标题与链接语法），**没有一章丢尾**。
差的是：

1. **spine 里有 39 个 TOC/NCX 之外的单条脚注文档**（`34_Footnote.xhtml` … `72_Footnote.xhtml`，
   合计 11,220 字）。每页只有一个 `<div class="footnote">`，内容是正文里 `*` 号脚注的正文，
   带指回所属章的 backlink。转换器按"页外页取自己第一行当标题"的规则，把它们写成了 39 个
   「章」，标题就是那条注的第一个词：`Please`、`Knowing`、`Alert`、`The`、`For`、`It`……
   另有 3 页首行取不出标题，落成 `前置页 34 / 62 / 64`。于是这本 15 章的书报出 64 章，
   第 26–64 章全是这种十来个字到一千字的碎片。同一段页外文字里还有 `next-reads.xhtml`
   （114 字，推荐别书的广告页）也混成了章。
2. **audit 的 13% 缺口对得上，不是漏正文**：本章节的 md 侧字数比 raw 还略高（重出后
   515,872 对"应得"500,505，多出的约 15,400 是 Notes 里 239 条 URL 在 markdown 里既是文字
   又是链接目标，被 audit 数了两遍）。真正的缺口是菊花页：`Preface to the Final Edition`
   8,646 字被标题过滤器当前置页排除，`Epilogue` 是 NCX 里的正文章节（第 30 条、正文最后一篇）
   却被当成卷尾页排除，`Notes` 33,446 字（按章分组的尾注，带引文与解释性短句）同样被排除。
   三页合计 48,362 字 ≈ 全书 8.8%，是这本书 body-only 的天花板：任何"正文全对"的跑法都只能到
   86.8%。

## 改动（只动批次覆盖选项，不碰库、不碰脚本）

`工作区/批次/split-ops-20261025-204703/overrides/B1727.json`

```json
{
 "args": ["--keep", "^Notes$", "--keep", "^Epilogue", "--no-untoced"]
}
```

- `--keep "^Notes$"`：尾注不是书目清单，是按章编号的引注 + 解释性短句，捞回来成第 26 章
  （`26_Notes.md`，54,520 字）。顺带的好处：正文里原来只是裸 `^3^` 的脚注标记变成
  `[^3^](26_Notes.md)`，点得过去了（与本批次 B1720《Irrational Exuberance》同一处理）。
- `--keep "^Epilogue"`：`Epilogue` 是 NCX 第 30 条、正文最后一篇（作者回顾 2008 与 2021
  两个时间点、盘点 nudge 这十几年的落地），标题过滤器当卷尾页排除了，是误判，收回来成第 24 章。
- `--no-untoced`：去掉 39 条脚注碎片 + `next-reads` 广告页。它们不是章：一页一条注，
  没有标题可给，收着就得到 39 个叫 `The`、`For`、`If` 的"章"，README 目录与检索层都会被污染。
  **代价说清楚**：这 11,220 字（2.1%）是书里真实的脚注正文，本次随选项一起排除，源文件里随时
  可查。正文里它们的标记保留为裸 `*` / `^N^`，其中 `^N^` 指到 `26_Notes.md`。
- `Index`（24,449 字，词条+页码）仍按默认排除：进 md 只会给检索层灌人名与页码噪声，
  不收它比例已到 94.3%，没有为凑数收它的必要。

没有改章节边界、没有改章名、没有复制段落、没有为抬比例加字：24 个原有章节文件与新产物逐字节
比对，唯一差别是脚注标记的链接语法（`^3^` → `[^3^](26_Notes.md)`；指向被去掉脚注页的
`[*](34_…md)` → 裸 `*`）。把这两种标记归一成裸标记后，24 章正文完全相同（脚本核对：
共享章 24，归一后一致 24，不一致 0）。
