# pdf-text-2026-10-19 批次说明

把 primary 源是 PDF、且有文本层的书直接抽成 md（不切章、不调接口、不花 OCR 额度）。
范围来自 `工作区/批次/pdf-普查-2026-10-19/triage_final.csv` 的 `route=本地抽文本`：
56 本 14,475 页。

## 结构规则（操作人 2026-10-19 定）

- **纯文本层且 PDF 自带可用目录** → 按目录切章，一章一个文件；
- 其余 → **只生成一个内容文件** `md/<书名>.md`。

目录可用的判据（`pdf_text_to_md.py` 的 `usable_toc`）：条目 ≥3、全书 ≥20 页、每条页号都在
1..页数 内且不回退。判不过就记 `toc_rejected` 的原因，走单文件。切章取最浅层的条目做章首，
每章覆盖 [章首, 下一章首-1]，目录首条之前的页并进第一章，所以一页都不会丢；章内正文空的不写，
数目记 `empty_chapters`。

## 产物

`pdf_text_to_md.py` 抽正文（`get_text("dict")` 按读序，文字块成段、图块换成 `![](images/…)`），
README 与 `.manifest.json` 复用 `pdf_ocr_to_md.py` 那套生成器。宽或高 <64 px 的图丢掉并计数
（`images_dropped`，多为装饰与字形图）。落库前过两道门槛：

1. `verify_output.py` 退出 0（链接、图片、front matter、重复文件）；
2. `pdf_audit_volume.py`：md 正文计数字符数占 PDF 文本层的比例 ≥95%，逐页锚点（每页跳过前 10 个
   计数字符后每 20 个计数字符一个窗，去空白后在 md 里找）覆盖 ≥90%。字数比会略大于 100%，
   因为章标题与目录页文字在 md 里多算了一遍。

## 复跑

```bash
cd ~/文档/books
PY=工作区/.venv-pdf/bin/python
$PY 工作区/脚本/pdf_md_batch.py --batch pdf-text-2026-10-19 --route text --workers 4   # 已落地的自动 skip
$PY 工作区/脚本/pdf_md_batch.py --batch pdf-text-2026-10-19 --route text --report
$PY 工作区/脚本/pdf_text_to_md.py --pdf <源> --out <暂存> --uid … --title … --structure auto
$PY 工作区/脚本/pdf_audit_volume.py <源.pdf> -o <md目录>
```

单本暂存产物在 `out/<uid>/`，过检后 `os.rename` 进 `库/<书>/md/`；被替换的旧版会改名留在 `out/`。
