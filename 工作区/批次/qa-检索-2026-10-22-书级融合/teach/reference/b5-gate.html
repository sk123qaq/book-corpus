B5 读数速查

书卡与门槛 · 一页速查 · 2026-10-23

书卡不是搜索框，是首轮之后的一次「你选哪本」的机会。这一页只记两件事： 什么情况下弹卡，以及 gate.tsv 的每个数怎么读。

审计修订（2026-10-23）：本页旧版的 +19 / +1.7 是旧口径。全词选章后复跑：触发题卡片 top3 15/21=0.714、top6 17/21=0.810；循环 top3 15/21、top5 17/21；全部题实际默认 53/60=0.883，循环 top5 53/60=0.883。卡片的同宽检索收益为 0。旧数字保留 在下面的「旧口径」里；新口径见 审计速查。

一、触发规则

规则条件备注
1top1 与 top2 的书级分差 < 10%系统自己也不确定
2top10 跨至少三个类型类型 = 社科 / 文学 / 网文类型 / 生活实用…
3top10 里有 ≥50 章的书几乎总会成立，单靠它不窄
4概念型开放问题，且无书名/作者提示概念表命中或问句词
抑制书名查询 / 作者查询 / 原句查询任一成立就不弹，优先于四条规则

书名判断：3 字以上书名出现在问句；2 字书名要求问句等于它，或以它开头且下一字是 「里/中/内/的/讲/说/是/这/那」；《…》 里的书名也算，即使库里没有这本书。 作者判断：作者名出现，且没有问句词，或作者名占问句一半以上。原句判断：引号里 ≥8 字， 或 ≥12 字且没有问句词。

二、卡片字段

字段意思看什么
title / type / chapters书名、类型、章数先排除明显不对的类型与体量
best_chapter / best_chapter_title系统会先读的那一章章名是否像答案所在
snippet该章最好的一段正文，≤150 字是不是正文，不是脚注/标题
matched_groups这本书命中的查询组缺了哪一组，为什么
score / reason书级分与分项：名次、best、support、cov分差小的时候看 support 与 cov
readme_status章节目录来源：ok / partial / missingmissing 时章名来自文件名

三、门槛字段

字段意思怎么算
n题数gold 60
trigger弹卡的题数四条规则任一成立且无抑制
auto_hit首轮 top1 书的前三章命中可接受章在 top1 书的前三章里
loop_hitB2.5 循环最终 top1 的前三章命中「最好的自动方案」
card_hit_triggered触发题上，用户选中目标书后的命中目标书在卡里且前三章命中；上限
auto_hit_triggered触发题上，首轮 top1 的命中同一批触发题
loop_hit_triggered触发题上，循环 top1 的命中同一批触发题
loop_top3 / loop_top5循环前 3 / 前 5 本书的命中和卡片同宽比较时用它
card_top3 / card_top6卡片前三 / 前六的命中默认入口六张都展开；top3 是诊断
effective_hit合并口径：触发题用卡，未触发题用 auto卡片只在触发时存在
kept_hit排除卡片里长书最多的类型后的命中诊断「排除类型」的代价
gain_vs_loop全部题：effective − loop门槛看它是否 ≥ +10 点
gain_vs_loop_triggered触发题：card − loop卡片真正生效的题
long_auto / long10_autotop1 / top10 的长书占比长书 = ≥500 章
long_loop循环 top10 的长书占比长书门槛的基线
long_effective展示列表的长书占比触发题看卡，未触发题看 top10
long_cards_triggered触发题卡片列表的长书占比6 张卡里几本 ≥500 章
long_kept排除类型后的长书占比降了，但命中也会掉
target_shown目标书出现在卡里的题数卡片命中的前提
pass_gain_* / pass_long_*两条门槛路径命中 +10 点，或命中不降且长书占比降
recommend旧值 opt-in / drop审计后等宽收益 0；默认展示是产品决定，不再由触发子集单独判过

四、一个算例（审计后）

旧口径：60 题里 21 题触发，39 题不触发。触发题首轮 13 中、循环 top1 13 中、卡片 17 中； 不触发题走 auto 28 中。于是旧 effective=45/60=0.750，旧 gain=+1.7。

问题在宽度：卡片看 6 本，循环只看 top1。把循环也放到 top3/top5：

口径触发 21 题全部 60 题
循环 top113/21 = 0.61945/60 = 0.750
循环 top315/21 = 0.71450/60 = 0.833
循环 top517/21 = 0.81053/60 = 0.883
卡片 top3 / top615/21 = 0.714 / 17/21 = 0.810默认 53/60 = 0.883

触发题的 +4 是第 2、3 本书：循环 top3 本来就有它们，旧算法只算 top1。全部题的默认路径 （触发卡 + 未触发循环 top5）也是 53/60，和循环 top5 相同。卡片的检索收益为 0；旧 +19 / +1.7 是宽度差。

默认入口是触发卡六张 17 + 未触发循环 top5 36 = 53/60；自动循环 top5 也是 53/60。六卡默认不再比自动少 2 题；差别不在卡片，在展示宽度。

五、长书占比

口径值读法
auto top10.317首轮第一本里三成长书
auto top100.155前十里平均 1.55 本长书
loop top100.153循环基线
卡片展示（全部题）0.171比循环高，长书路径不过
卡片展示（触发题）0.1756 张卡里约 1 本长书
排除类型后0.122（全部）/ 0.033（触发）降了，但命中掉到 0.617 / 0.429
长书占比的分母不同：卡片侧除以 len(cards)（默认 6），循环侧除以 10。 一本长书在 6 张卡里是 0.167，在 top10 里是 0.100，所以旧 0.175 vs 0.153 有一部分是分母 造成的；要比较就统一成分数或同宽列表。

六、反馈字段

字段写什么
ts / query时间、问句
shown / selected / rejected展示了哪些书、用户选了哪些、排除了什么
types / chapters展示书的类型、章数
answer_found用户事后填 yes / no；B5 留空

非交互模式不写 selected，只给 default_selection；只有 --select 才把用户选择写进反馈。
