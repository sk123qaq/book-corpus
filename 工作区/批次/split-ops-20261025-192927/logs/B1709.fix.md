## 根因

源 EPUB 的 NCX 只有 17 条（Cover / Title / Copyright / Table of Contents / Preface /
PART ONE / 1. / PART TWO / 2. / 3. / 4. / PART THREE / 5.–9.），没有那两份 `ESSAYS`。
它们来自 spine 里两个**未被 TOC 收录**的半书名页：

- `BenS_..._part2.html`（封面之后、书名页之前）
- `BenS_..._part7.html`（Preface 之后、PART ONE 之前）

两页都只有一行 `<p>ESSAYS ON THE GREAT DEPRESSION</p>`，所以各自产出 37 字的同名文件，
被 verify 判成重复。默认转换会保留 TOC 未收录的页，于是这两页进了产出。
同一批未被 TOC 收录的还有 `part20.html`（Index），它本该由标题过滤器当卷尾页丢掉。

`02_Title.md`（96 字，NCX 里的 `Title`）是书名页：标题过滤器的英文卷首词表里有 Cover /
Copyright / Table of Contents / Preface，没有 `Title`，所以漏成了第 1 章。

## 改动

只加两条 `--drop`，章节映射与章名一概没动，正文一个字没改（见下节逐文件核对）：

`工作区/批次/split-ops-20261025-192927/overrides/B1709.json`

```json
{
 "args": ["--drop", "^ESSAYS$", "--drop", "^Title$"]
}
```

- `^ESSAYS$` 精确匹配那两份半书名页（全库唯一标题），连同重复问题一起去掉；
  两页都是卷首装饰页，不是任何一篇正文的题头。
- `^Title$` 去掉书名页。属于卷首页，不是正文章节；留着会让 README 目录第一行进
  “Title”，也是全库唯一一个以书名页当第一章的情况（本书只有 9 篇文章 + 3 个部分页）。

改后重跑转换（`--title "Essays on the Great Depression"` 与批次驱动一致），产物整体替换
暂存目录 `tmp/B1709/out`。
