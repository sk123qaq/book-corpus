# B1720《Irrational Exuberance》修单

## 原报的问题

- verify `problems: 0`，但有 1 份 132,345 字的怪章 `22_Khurana, Rakesh.md`。
- audit 84.8% `LOW`（683,266 / 806,063），差 3.2 个百分点才到 88% 下限。

## 根因（两件事，都不是拆坏的正文）

1. **正文本身没丢。** 24 个 TOC 单元里有 21 个正常出章；`Notes`（99,983 字）、
   `References`（36,269 字）按默认策略当卷尾页排除了，另有一页 TOC 未收录的
   `part0029.html`（16,313 字，标题也是 `References`，是附录诺贝尔讲座自己那份
   参考文献，条目里直接引 “Economic Sciences Prize Committee of the Royal …”）
   同样被当卷尾页排除。`Index`（22,907 字）是索引，排除是对的。
   这三页加起来 15.3 万字 ≈ 全书的 19%，所以任何"正文全对"的 body-only 跑法都只能到
   85%——不是截断，是这本书的卷尾页比一般书重。
2. **`22_Khurana, Rakesh.md` 是索引的后半截。** 源书的索引被 calibre 切成两个文档：
   `part0032_split_000.html`（TOC 的 `Index` 指向它，A–K）与
   `part0032_split_001.html`（TOC 里没有，K–Z）。第二个文档是 TOC 未收录页，转换器按
   "页外页取自己第一行当标题"的规则把它命名为 `Khurana, Rakesh` 并当成正文章节写出来。
   它的 132,345 判分不是正文被复制，而是索引条目被改写成
   `Khurana, Rakesh,[93](<08_…md>)` 这种形式后**链接目标文件名**被算进字数：raw 只有
   25,304 字，md 侧量到 108,917 字（4.3 倍）。同一本书的 `Index` 正页被排除、后页被
   收录，映射本身就错了。

## 改动

只加三条开关，章节映射与正文一个字没改：

`工作区/批次/split-ops-20261025-192927/overrides/B1720.json`

```json
{
  "args": [
    "--keep", "^Notes$",
    "--keep", "^References",
    "--drop", "^Khurana, Rakesh"
  ]
}
```

- `--keep '^Notes$'` 把尾注捞回成第 23 章（128,969 字）。它不是书目清单：里面有逐章
  编号的引注、原文引语与链接，属于正文的一部分。
- `--keep '^References'`（不带 `$`，故意让两条 `References` 都命中）捞回两份参考文献：
  第 22 章是附录诺贝尔讲座自己那份（18,738 字），第 24 章是全书主参考文献
  （42,365 字）。两份名单只有 17 条重名，不是同一份的复制，位置也照源书顺序：
  附录 → 讲座参考文献 → Notes → 全书 References。
- `--drop '^Khurana, Rakesh'` 去掉索引后半截那个被误认成章节的页。它属于 `Index`
  （卷尾页），与该书本来就排除的 `Index` 正页同性质，不是正文。
- 顺带的好处：`Notes` 有了落地文件之后，各章正文里的脚注标记从裸 `^1^` 变成
  `^[1](23_Notes.md)^`，脚注终于点得过去。21 个原有章节的正文文本除这一处链接语法外
  与改前逐字节相同（把 `[N](23_Notes.md)` 归一成 `N` 后逐行比对，全等）。

改后重跑转换（`--title "Irrational Exuberance"` 与批次驱动一致），产物整体替换暂存目录
`tmp/B1720/out`。

## 下次看这本书时的注意点

- README 里有两行都叫 `References`（22 / 24）。这是源书自己的两份名单：22 是附录诺贝尔
  讲座的，24 是全书主参考文献，顺序与源书一致，靠章号区分。别当重复文件合并。
- 一本书的 `Notes` 被排除时，正文里的脚注只剩裸 `^1^`；这类书（尾注、参考文献占 15% 以上）
  一眼就能从 audit LOW 看出来，先数卷尾页，别先怀疑拆章。
- 索引被 calibre 切成两页时，第二页会以"取第一行当标题"的规则冒充正文章节，标题通常是
  某个词条名（这里是 `Khurana, Rakesh`）。判据是：该文件体量远超它对应的 spine 文档，
  且内容全是 `词条,页码` 的行——`--drop` 掉，别去改正文。
