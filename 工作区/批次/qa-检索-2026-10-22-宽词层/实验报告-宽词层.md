# 宽词层实验报告

日期 2026-10-22。批次目录 `工作区/批次/qa-检索-2026-10-22-宽词层/`。

## 结论

宽词层在当前 40 题上**没有提升章级命中，提升了书级召回**。

- 章级 hit@10 从 1/40 到 1/40，hit@20 从 2/40 到 2/40，MRR 从 0.027 降到 0.009。
- 书级 hit@10 从 8/40 到 12/40，hit@20 从 9/40 到 14/40，书级 MRR 从 0.116 到 0.140。
- 17 道「目标章完全不含宽词」的题里，书级 hit@10 从 2/17 到 5/17，章级仍是 0/17。

所以宽词层现在只该当**捞书层**用，不能当章级排序层用。不要并进 126 个精确概念的主表。保留独立的两层：宽词捞书，读 `md/README.md` 选章，再回原文核引文。

## 设计

| 正义 | 公正,公平,应得,道义 | 正义联盟,正义使者,公平秤 |
| 秩序 | 规矩,次序,稳定,礼治 | 秩序册,顺序,工序 |
| 服从 | 顺从,听命,遵从,臣服 | 服从调剂,服从分配 |
| 孤独 | 孤单,寂寞,孤立,独处 | 孤独症,百年孤独,孤独星球,孤独的美食家 |
| 爱 | 爱情,亲密,依恋,感情 | 爱心,爱国,爱好,爱因斯坦,爱情公寓,爱的迫降,爱豆,爱国主义 |

`自由` 没有放进宽词层。它已经在 126 个主表里有键、别名和排除词，再放一遍只会重复。

### Runner

`工作区/脚本/qsearch_plan.py` 新增 `broad` 与 `broad_weight`。只有计划显式写 `broad` 才展开，不写就和以前完全一样。

```json
{
  "question": "权力为什么能让人听话？",
  "groups": [{"name": "literal", "terms": ["权力", "听话"], "weight": 1.0}],
  "broad": ["权力"],
  "broad_weight": 1.0,
  "book_hint": "",
  "exclude": []
}
```

宽词的排除词是**组内排除**。它只把含「权利」「控制台」的段落从宽词组里去掉，不会误删 literal 组的合法命中。概念组的全局排除逻辑没有改。

### Heldout

40 题，每个宽词 4 题，目标章与目标行都写进 `heldout.tsv`。构造规则：

- 问题里含宽词键。
- 目标行含该宽词的一个别名，不含宽词键本身。
- 目标行不含问题 literal 组里的任何词，保证行级无原词。
- 目标章在 `index.db` 里存在，逐行核对路径、行号、原文。
- 17 道题的目标章整章不含宽词键，作为严格子集单独报。

40 题的目标分布在 12 本书，主要是乡土中国、乌合之众、圆圈正义、政治秩序的两本、大断裂、亲密关系、爱的艺术、不能承受的生命之轻、百年孤独、质数的孤独。

## 为什么章级没涨

目标段落都在索引里。我逐题查过 `para` 表，40 个目标章都有含别名的段落。问题不在索引缺失。

问题在宽词的排序。以 b001 为例：

- 目标行是乡土中国重刊序言里的「支配着社会生活的各个方面」。
- 宽词组 `权力 OR 支配 OR 强制 OR 权势 OR 统治` 在全库有几万段命中。
- 目标段落在宽词组里排到 2000 名之外。把 pool 放到不限、group_limit 放到 2000，仍然进不了宽词组前 2000。
- 章级 RRF 只取每组前 100 段，目标段落在融合前就已经丢了。

b017 的「孤立」也一样。宽词组全取时目标段落排到 1554 名。宽词太常见，目标行只有一次别名，压不过别名密集的段落。

书级能涨，是因为目标书里别的章、别的段落在宽词组里名次更靠前，整本书被捞进 top10。章级不涨，是因为 RRF 把宽词组的噪声一起带进来，目标章的精确名次没有改善，b038 还从第 1 掉到第 3。

## 这个 heldout 的边界

40 题是「宽词 + 一个不在目标行里的泛词」的泛问句，例如「权力为什么能左右普通人的日常生活？」。这类问题本来就有很多合理答案，单章 gold 只认一个章，太严。1/40 不等于宽词层什么都搜不到，它只说明那个指定章没进前 10。

所以这次读数适合回答「宽词层能不能把书捞出来」，不适合回答「宽词层能不能把唯一正确的章排到第一」。后者需要多章可接受标注，或者两阶段：先捞书，再读目录选章。

## 决定

1. 不并入 `目录/概念表.tsv`。126 个精确键保持不变。
2. `目录/概念表-broad.tsv` 保留为独立实验层。`qsearch_plan.py` 支持它，但默认不启用。
3. 生产用法只到书级：宽词计划捞 top 书，agent 读 `md/README.md` 选章，再 `grep -nF` 核引文。
4. 不按宽词逐键调权重。40 题上 0.6 的书 hit@20 是 15/40，1.0 和 1.2 是 14/40，差异太小，逐键调就是过拟合。
5. 下一步若还要做章级，先做**书级融合**：宽词组按书聚合，和 literal 的书级名次融合，再在 top 书里选章。不要继续加大章级 RRF 权重。
