# 追问页 · 五个前端变体

## 决策

现有的「书库检索」页是一个单次流程：一句问题，五个阶段，落到原文。现在要回答完之后还能继续问。真正要定的是结构：**追问之后，上一轮的检索过程去哪了，新一轮跟上一轮是什么关系。** 这次只画前端，不接功能。五个变体是五个答案，不是五套皮肤。

## 固定的东西

皮肤不动，比较的才是结构。

- 载入 `shared/tokens.css`（`<link rel="stylesheet" href="shared/tokens.css">`）。纸 `#f6f3ec`，卡片 `#fffdf8`，墨 `#1d1c1a`，朱红 `#a63d2f`，细线 `#d9d2c4`。不要改这些值，不要加第二套色。
- 字体只用 `--serif` / `--sans` / `--mono` 三个栈。不引外部字体。
- 内容全部来自 `shared/content.md`，逐字用，不要自己另写一段回答。
- 页头用 `.masthead` + `.brand` + `.stats`，五个变体一致。
- 右下角放一个 `.proto-tag`：`原型 · 引文真实，耗时与计数为示意`。
- 五阶段名字固定：`01 理解问题` / `02 词法循环` / `03 打分与选章` / `04 书卡` / `05 结果`。每个变体都必须能看见它，只是位置和形态不同。

## 硬约束

- 单文件 HTML，CSS 写在 `<style>` 里，共享 token 用 link。不引 CDN、图标库、npm、外部图片。插画只用 CSS 或内联 SVG。
- 桌面 1440×900 是一等公民，整页在 900 高内能看出结构。窄到 390 不许横向滚动，布局降级要设计过，不是挤成一团。
- 中文界面。不用 emoji。不用渐变、玻璃拟态、彩色阴影、大面积色块。
- 不做功能：不做真实对话、不请求接口、不连后端。可以用 20 行以内的 JS 做选中态或滚到某段，但不写业务逻辑。
- 必须 `file://` 直接打开就能看，不依赖本地服务。
- 只写自己那一个文件。`shared/` 与别人的变体只读。

## 共同要画出来的状态

1. 第 1 问已经答完，第 2 问（追问）也答完，第 3 问可以画成已答或"正在等下一句"，二选一，但输入框必须处于已聚焦、有光标的状态。
2. 引文要能看出是可点的依据，不能只是一行灰字。
3. 追问入口要明显，一个第一次看的人不用猜"还能不能接着问"。
4. 每一轮的检索过程都要有去处，不能因为追问就消失。
5. 页面上最多标注一次「本轮翻了几本、命中几段、多久」。

## 五个变体

### v1-chat.html · 对话流接管

赌的是：答完之后，这个页面就该变成对话。

- 单栏，宽 760 左右，居中。第 1 问顶部一行「第 1 问」+ 问题（衬线 22），下面回答是正文段落，不用气泡。
- 每轮回答上方压一条 40px 高的「本次检索」带：五个小点、`2 本 · 9 段 · 1.8 s`、右侧「展开过程」。展开态可以画成第二条带下面的五阶段横排。
- 轮与轮之间留 40px，靠一条短朱红竖线分节。
- 引文不进正文。正文句尾用 `.cite` 上标 `[1]`，回答下面排「依据」三行，每行书名 · 章 · 引文首句 + 「展开原文」。
- 底部 composer 固定在视口底，宽 760，上方三个建议追问 chip，输入框里有光标，右侧朱红「接着问」按钮。
- 交互暗示：向上滚动能看到更早的轮次，顶部有一条"回到最早"。

### v2-split.html · 三栏研究台

赌的是：追问时最不该丢的是原文，而落点该由人选，不是每问都有。

- 三栏。左 300：会话线索，三问用一条竖线串起来，每问上方写它跟上一问的关系（`承接 01 [2] 愈推愈远，也愈推愈薄` 或 `同书追问 没有选落点`）。当前条左侧朱红竖条与实心节点。
- 中 1fr：当前轮。问题、五阶段窄条、落点行、回答、依据。有落点时落点行是 `追问落点 · 来自 01 [2] 愈推愈远，也愈推愈薄`，红箭头指右栏；没有落点时换成虚线范围行 `范围 《乡土中国》 · 没有选依据 · 这一问不带落点框`。
- 右 380：证据抽屉。顶部 `[n]` + 书名，选中时加「落点」角标与「已选为下一问的落点 · 再点一次取消」，未选中时提示「点这段，设为下一问的落点」。中段原文，下段上下文与「上一段 / 下一段」。
- 选依据：点回答里的上标、依据行、抽屉里的 `[n]` 或原文段，都会选中并钉住右栏；再点同一条取消。选中时输入框上方写「下一问挂在 [n] …」，取消后写「不选依据就是整轮追问」。
- 输入框占位随选中变化：`就 [n] 这一段接着问` 或 `接着问，不选依据也能问`。
- 窄屏：右栏变成中栏底部的抽屉条，左栏变成顶部横滑三条，输入区 sticky 在底部。
- 交互：点左栏 01 / 02 / 03 换轮次。第 2 问有落点，第 3 问没有，两态同页可切。

### v3-tree.html · 追问树

赌的是：追问问的是某一段，不是"第几轮"。

- 单栏，宽 820，像书页。主回答的三段之间留 28px。
- 每段右侧（窄屏在段末）一个 26px 的圆形 `+` 追问钮，`+` 旁边一行 11px「追问这段」。
- 第 2 问挂在第 1 问第二段的下面：缩进 56px，左边一条 1px 竖线与一个小圆点接回该段，卡片底色 `--soft`，无边框或只有上边线。第 3 问挂在第 2 问的回答下面，再缩进 56px。树深两级即可。
- 顶部一行：`第 1 问 · 2 个分支`，右侧一个极小的分支地图（`1 → 1.1 → 1.1.1`、`1 → 1.2` 用线连）。
- 底部 composer 上方固定一行锚点提示：`锚在「愈推愈远，也愈推愈薄」· 点 × 取消`，输入框 placeholder `就这一段接着问`。
- 交互暗示：回答是可以被拆开追问的；换锚点就能换一棵子树。

### v4-ledger.html · 问题簿

赌的是：多轮要能查账，不要变成聊天记录。

- 全宽 1100，账页。左 150 固定装订栏：每条记录的序号（`01` 衬线 28）、日期 `10-27 14:32`、`1.8 s`、`2 本`，一律 mono 11px，靠右对齐。
- 正文列宽 1fr，每条记录一行问题（衬线 21）+ 回答（15px，最多四行）+ 依据一行（`乡土中国 · 差序格局 · [1] [2] [3]`）+ 右侧「展开过程」。
- 记录之间 1px 实线，不留大空隙。最新一条默认展开：回答全文 + 依据三行 + 内嵌一条紧凑的五阶段横排（五格，每格标题 + 一句读数）。
- 右 90 固定页签列：`1 / 2 / 3` 竖排，当前条朱红，其余灰，附一条细竖线。
- 底部一行是账本的下一行：左侧 `04` 与当前时间，右侧输入框（无边框，只有下划线或左竖线）+ 「记下」。placeholder `续记一问`。
- 窄屏：装订栏收到记录上方一行，页签列隐藏。
- 交互暗示：这一页会一直往下长，但每一条都有编号和读数，可以回看、可以引用。

### v5-turn.html · 翻页

赌的是：一次只看一问，历史是导航，不是堆积。

- 保留今天的骨架：顶部一条问题栏 + 左 280 流程轨 + 右五阶段卡。问题栏改成翻页器：左 `‹ 上一问`，中间 `差序格局的波纹`（衬线 20）与 `2 / 3`，右 `下一问 ›`。
- 问题栏下一行面包屑：三个问题，一行，当前加粗并带朱红下划线，其余灰；右侧 `会话 3 问 · 12.4 s`。
- 五阶段照旧，第 2 问的五阶段照实画（第 4 阶段显示「这本书精确命中，跳过书卡」）。第 5 阶段末尾接一张虚线框的「继续追问」卡：输入框 + 三个建议 chip + 「问」。焦点态可见。
- 页面右边缘一条竖排页码 `1 2 3`，当前朱红实心，其余空心小圆，在最右侧距边 18px，sticky。
- 窄屏：流程轨照旧收成顶部五段进度条，翻页器收成 `‹ 2/3 ›`，页码列隐藏。
- 交互暗示：追问不会让页面变长，只会多一页；老的那一页完整保留，包括它的五阶段。

- 图的路径：`原型-追问/shots/vN-1440.png` 与 `vN-390.png`。
