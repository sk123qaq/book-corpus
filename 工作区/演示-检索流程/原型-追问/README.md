# 追问页 · 五个前端方向

原型，不是成品。`原型-追问/index.html` 直接双击打开，`1` 到 `5` 切变体，`0` 回总览，`index.html#v2` 直达某一版。

## 这次要定的问题

现在的「书库检索」是一次性流程。一句问题，五个阶段，落到某本书某一段。加「回答完还能继续问」时，真正要定的是结构。

追问之后，上一轮的检索过程去哪了。新一轮跟上一轮是什么关系。

皮肤不动，纸、墨、朱红、衬线标题、等宽读数全部沿用，五个变体只换结构。这样比出来的是结构差异，不是审美差异。

## 五个方向

| | 变体 | 赌的是 | 追问入口 | 五阶段去处 | 代价 |
|---|---|---|---|---|---|
| 01 | 对话流接管 | 答完就该是对话 | 底部固定输入框 | 每轮回答上方一条可展开的窄带 | 管线不再显眼，回看过程要点开 |
| 02 | 三栏研究台 | 追问时最不该丢原文 | 先选依据，再在中栏底部问 | 当前轮回答上方的窄条，可展开 | 三栏吃宽，窄屏要折叠 |
| 03 | 追问树 | 追问问的是某一段 | 每段右侧的「追问这段」 | 主问的阶段挂在树根，每枝各自带一条 | 不按时间读，深树在手机上难扫 |
| 04 | 问题簿 | 多轮要能查账 | 账本最后一行的「续记一问」 | 最新一轮内嵌紧凑五格 | 像登记簿，不像对话 |
| 05 | 翻页 | 一次只看一问 | 第 5 阶段末尾的追问卡 | 每页完整保留，翻页即回看 | 不能并排比两轮 |

五版都用同一份内容。三个回合，都关于《乡土中国》的差序格局。引文逐字取自库里 `06_差序格局.md` 与 `07_维系着私人的道德.md`。页头的 1,779 本、2,640,800 段、90,769 章取自 `library.db` 与 `index.db`。每轮的耗时、翻书数、命中段数是示意值，页面上有标注。

## 02 的两种追问

选依据是追问的前置动作，不是装饰。

**有落点。** 在第 1 问里点 `[2]`，右栏钉住那段原文，输入框上方出现「下一问挂在 [2]」。问出去，第 2 问顶部就有一行「追问落点 [2] 愈推愈远，也愈推愈薄」，红箭头指到右栏。左栏第 2 问上方写「承接 01 [2]」，这条线让 01 到 02 的来路看得见。

**无落点。** 不选依据直接问，或者选中后再点一次取消。第 3 问就没有落点框，只有一行虚线「范围 《乡土中国》 · 没有选依据 · 这一问不带落点框」。左栏写「同书追问 · 没有选落点」，输入框提示「不选依据就是整轮追问」。书范围照旧继承，落点不继承。

两态都在同一页里，点左栏的 01 / 02 / 03 切换。第 2 问是有落点的，第 3 问是没有的。截图见 `shots/v2-1440.png` 与 `shots/v2-1440-t3.png`。

## 怎么看

第一眼看追问入口。找到它要不要猜。

第二眼看管线。上一轮的 01 到 05 还在不在，在什么位置。

第三眼看关系。两轮之间是流、是栏、是树、是账、还是页。

## 推荐

**已选 02 三栏研究台，并把 03 的锚点做成可选的前置动作。**

理由有三条。

这个书库卖的是原文。追问的典型动作是「这句再往下说」，不是「换个话题」。02 把原文常驻在右栏，点任意上标就换证据，追问时眼睛不用离开引文。

管线是这页的身份。02 把它收成一条可展开的窄条，既让位给对话，又没有丢。

03 的「追问这段」是五个变体里最值得偷的一个动作。它把追问从「再问一句」变成「就这一段问」，也给右栏一个天然的锚。把这两个动作并在 02 上，成本很小，产品味道最足。

不建议直接上 01。它最省事，也最容易做成一个普通聊天框，书库的检索过程退化成折叠条。上线后用一周，大概率没人会展开它。

05 是改动最小的路线。如果这一版只想加一个追问入口，不想动布局，05 可以直接上，代价是历史只能一页页翻。

## 复跑

```bash
python3 工作区/演示-检索流程/原型-追问/shoot.py     # 1440x900 与真实 390x844 各出一张，顺带量横向溢出
```

`shoot.py` 用 CDP 的 `Emulation.setDeviceMetricsOverride` 定宽度，因为 headless 的 `--window-size` 最小只到 500。五份文件在 1440 与 390 下 `scrollWidth` 都等于视口，没有外部请求，控制台没有报错。每个变体两张图在 `shots/vN-1440.png` 与 `shots/vN-390.png`。

原型是丢掉的东西。选定方向之后走 Feature，不要在这五个文件上演进。
