# 会话历史 + 阶段进度 · 前端设计原型

这是 throwaway 原型。不接后端，不改 `web/`、`server.py`、`answer.py`。数据取自
`缓存/sessions/a0ab475a63e6` 的第 2 问（真实一轮），历史列表是 10 条真实会话摘要。

已定：阶段区用横条，回答落地后卡片自动收起，左栏保留「本次会话 / 历史会话」加「接着上次」。
这版只重做横条下面的展开区，给了四版，另把回答段落标题的字号改成和正文一样。

## 看

```bash
cd ~/文档/books
python3 -m http.server 8799 --directory 工作区/演示-检索流程/原型-会话历史
# http://127.0.0.1:8799/
```

顶部黑条是原型控制，不是产品界面：

- `初始页 / 检索中 / 回答中 / 完成 / 展开卡片 / 历史切换`：整页状态。
- `展开样式 V1–V4`：同一份数据换四种展开区，横条不动。
- `▶ 演示进度`：从 01 走到 05，结束后必须 `active=0, done=5`。

## 四版展开区

横条始终是 `01 理解问题 / 02 词法循环 / 03 打分与选章 / 04 书卡 / 05 结果`，
圆点状态不变。四版只改横条下面那摞。

**V1 居中索引。** 每行只有居中的 `01 理解问题`，耗时靠右。摘要不进收起行，进展开体：
`5 组词 · 礼治 · 礼治秩序 · 差序格局`，下面接线索、词 chips、原始数据。五条发丝线，没有卡片框。
这是你提的那版，最安静，但收起时只看得到阶段名。

**V2 时间线。** 左侧一条竖线加圆点，阶段名下面挂摘要，耗时靠右。展开体是缩进的一块软底，
里面是线索、chips、原始数据。最接近 `/classic` 的 rail，信息最多，也最高。

**V3 单卡手风琴。** 五个阶段装进一个外框，内部发丝线。收起行是 `01 理解问题 5 组词 0.2 ms`，
展开体是软底，带标签：`检索词 / 轮次 / 排序 / 候选 / 命中`。没有五张独立卡片的感觉，最像成品组件。

**V4 台账。** 顶部一行 `阶段 / 摘要 / 耗时`，下面列对齐。收起行放短值，展开是一条数据带，
`摘要 / 细节 / 线索` 三行。右上用 `+ / −`，不是箭头。最密，最像实验记录。

## 边界

- 390 宽的历史只保留最近几条横滑，搜索与分组隐藏。
