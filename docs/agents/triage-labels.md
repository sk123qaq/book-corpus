# Triage Labels

技能里的五个 triage 角色，在本仓就是五个同名标签，已经建全（`gh label list` 可核对）。下面的「含义」与标签描述保持一致，改标签时两处一起改。

| 角色 | 本仓标签 | 含义 |
| --- | --- | --- |
| 待评估 | `needs-triage` | Maintainer needs to evaluate this issue |
| 待补信息 | `needs-info` | Waiting on reporter for more information |
| 可交给 agent | `ready-for-agent` | Fully specified, ready for an AFK agent |
| 需要人做 | `ready-for-human` | Requires human implementation |
| 不做 | `wontfix` | This will not be worked on |

技能里说到某个角色（例如「打上 AFK-ready 的 triage 标签」）时，用上表右列那个字符串。新增角色先建标签、再改这张表。
