状态：implemented · 2026-11-16
验收：uv run --frozen pytest -q && uv run --frozen book-corpus docs check --data-root ~/书库
历史背景（已标记 superseded）：[`docs/design/分层读-方案-2026-11-11.md`](分层读-方案-2026-11-11.md)、[`docs/adr/0002-three-tier-reading.md`](../adr/0002-three-tier-reading.md)、[`docs/adr/0003-reading-modes-and-panels.md`](../adr/0003-reading-modes-and-panels.md)

## 1. 问题诊断与产品转向

以 `B1896/01`（《深入浅出数据分析》开篇《Acme化妆品公司需要你出力》，全章 12 个原文块、约 850 汉字）为例，旧「工单 + 切块 + 多档预生成」体系存在根本性定位偏差：

1. **读即被阻断**：`service.py` 把 `preview_blocks` 切片成 `[:8]`，进章页看不到全文，必须先选读法、等 2–3 分钟生成完再跳转 `/reader`。
2. **工单名实不符**：`apps/reading/server.py` 的 `_post_job` 直接丢弃请求里的 `tiers`，勾选「速览」却强跑全部 5 层（`r-12a4f4de6b` 耗时 178.8 秒、消耗 25,467 tokens）。
3. **短章注水无深度**：`skim.py` 因不足 `MIN_SOURCE_HAN = 1200` 判 `supported=false`，但 `deep.py` 受 `MIN_NOTE = 80` 和「禁写书外事实」约束，硬对 850 字导读写出 10 条 1,800+ 字元评论。
4. **噪音代码过多**：三档投影、旧编辑层、视觉读本 `edition`、工单队列 `jobs` 与五层 `depth/` 互相缠绕，继续叠加功能会让代码库与文档持续积累噪音。

因此，本次重构明确做**减法 + 转向**：
- **彻底下线**工单系统、`edition` 视觉读本（待日后重设计）、`depth/` 五层编译与旧三档链路，不留兼容兜底死代码；
- **章节页即阅读工作台**：打开就是 100% 完整正文，顶部和划词提供轻便工具按钮（知识地图、图解、讲人话/举例、翻译、拆前提）；
- **`/records` 页面转型**：清空全部历史工单数据，定位为**各章节各功能的操作日志**。

## 2. 新旧界面与路由对比

```text
【旧路径（整体退役）】
/book/<uid> ─▶ /chapter/<uid>/<n>（切块[:8] + 读法选择 + 工单 + 视觉读本按钮 + 五层面板）
                  └─ 等数分钟 ─▶ /reader/<uid>/<n>[/depth|/edition]
/records（工单状态机队列 + 磁盘旧包清单）

【新路径】
/book/<uid> ─▶ /chapter/<uid>/<n>（阅读工作台：100% 完整正文，0 秒直出）
                  ├── 顶栏常驻工具：知识地图 / 核心术语 / 隐批 / 冷暖纸 / 夜读
                  ├── 划词浮动条：选中任意段落/句子 → 图解此段 / 讲人话举例 / 翻译原词 / 拆前提 / 追问
                  └── 右侧伴读抽屉：SSE 流式输出 + 钉住为该段永久旁批
/records（章节功能操作日志：按章聚合 + 流水查看 + 跳回章节段落）
```

## 3. 新阅读页与日志页交互设计

### 3.1 章页（`/chapter/<uid>/<n>`）
- **主区（100% 逐字正文）**：直接渲染 `mdparse` 全部 `blocks`（保留原图、表格、引用、列表），每块保留稳定 `data-block="B01"` 锚点与极轻的段落触发点 `✦`；已钉住的旁批以可折叠角标挂在段落旁，支持顶栏一键隐藏。
- **顶栏常驻工具**：
  - **知识地图 / 思维导图**：按需生成整章结构图（点击节点高亮跳转到对应正文块），结果缓存复用。内置**短章/扁平结构门控**（如 `B1896/01` 仅 850 字），不值得画图时直接提示「本章篇幅较短、脉络单一，建议直接阅读原文」，不强行注水（仍提供「仍要展开简图」手动选项）。
  - **核心术语 / 背景补充**：提取本章概念并允许补充书外前置常识，明确用 `[原文]` 与 `[补充]` 区分来源。
- **划词浮动工具条（Word 式交互）**：
  - 鼠标拖选任意正文（自动映射覆盖的 `block_ids` 与 `selected_text`）即在选区旁弹出浮条：
    - **图解此段**：把流程、因果、对照关系转成内联 SVG/结构图（复用图族渲染器）；
    - **讲人话 / 举个例子**：用大白话转述并举出生活/工程例子（放开「禁写书外事实」限制）；
    - **翻译 / 还原原意**：按文本特征自动切换「文言今译 + 典故注」或「译本英文原词/原意对照」；
    - **拆解前提**：只在读者主动点击时针对选区列出隐含假设与适用边界；
    - **问这句**：带入当前段落上下文在右侧抽屉自由追问。
  - **钉住（Pin）机制**：伴读回答默认临时展示；点「钉住到此段」后落盘，下次打开该章自动回显。
- **书型「读法」退居后台**：`profile.py` 不再阻塞阅读或要求进章前勾选，仅作为后台提示词路由与浮条按钮优先级依据。

### 3.2 记录页（`/records` → 章节功能操作日志）
- **删除现存工单数据**：清理 `~/书库/工作区/阅读/jobs.json` 全部历史工单，不再存在「排队 / 取消 / 重跑五层 / 已阻断工单」概念。
- **新日志模型（append-only `ops_log.jsonl`）**：
  - 每当读者在章节页调用一次功能（生成知识地图、划词图解/翻译/讲人话/拆前提/追问、钉住或移除旁批），向 `工作区/阅读/ops_log.jsonl` 追加一条记录：
    `{id, ts, uid, n, chapter_title, action, block_ids, status, model, tokens, elapsed_ms, summary, error}`。
  - 页面提供按书/按章节/按功能类型（`知识地图` / `划词伴读` / `旁批变更` / `失败`）过滤，点击条目可直接跳回 `/chapter/<uid>/<n>#blk-<id>` 复看或重新生成。

## 4. 接口设计（全面去掉工单与 `edition`）

### 4.1 章节与伴读接口（`apps/reading/server.py`）
- **`GET /api/chapter/<uid>/<n>`**
  - 返回：`book`、`chapter`、`blocks`（完整正文块）、`reading`（后台自动推断建议，不阻断）、`assist_notes`（已钉住的局部旁批）、`chapter_map`（已缓存的知识地图与门控评估，未生成为 `null`）。
  - **移除字段与路由**：移除 `tiers`、`standard_blocks`、`preview_blocks`、`gates`、`edition`、`edition_fit`、`depth`；移除 `/reader/<uid>/<n>`、`/reader/<uid>/<n>/depth`、`/reader/<uid>/<n>/edition`、`/api/jobs*`、`/api/depth*`、`/api/edition*`、`/api/export*`。
- **`POST /api/assist`（SSE 流式局部伴读）**
  - 请求：`{uid, n, action: "diagram|explain|translate|critique|ask", block_ids, selected_text, question?, stream: true}`
  - 响应：`text/event-stream`（`delta` / `diagram` / `done` / `error`），同时在服务端写入一条 `ops_log.jsonl` 日志。
- **`POST /api/assist/pin` & `DELETE /api/assist/pin/<note_id>`**
  - 持久化或删除某段旁批至 `工作区/阅读/<uid>/ch/<n>/assist_notes.json`（按 `source_sha256` 校验），同步记录 `pin`/`unpin` 操作日志。
- **`POST /api/chapter-map/<uid>/<n>`（全章知识地图与核心术语）**
  - 请求：`{force: false}`。先跑短章/扁平门控，未通过且 `force=false` 时直接返回 `{"supported": false, "reason": ...}`；通过或强制触发后缓存至 `chapter_map.json` 并写操作日志。
- **`GET /api/records`**
  - 读取 `ops_log.jsonl` 返回 `{logs: [...], chapters: [...], summary: {...}}`（按时间倒序与按章聚合），彻底替换原有的 `{jobs, packs}`。
