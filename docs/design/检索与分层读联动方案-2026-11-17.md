# 书库检索与分层读联动重构方案

状态：implemented · 2026-11-17
验收：`uv run --frozen pytest` 与 `uv run --frozen pre-commit run --all-files` 全过

## 1. 背景与重构目标

检索页（`apps/demo/`，8765）与分层读（`apps/reading/`，8771）分别承担「跨库找书找段 + 带证据回答」与「整章正文直出 + 结构地图 + 随文划词伴读」，此前存在三处结构性断层：
1. **地址体系不一致**：检索输出 `path`（`books/<uid>/md/<file>.md`）+ 1-based `line` + `quote`；分层读路由是 `/chapter/<uid>/<n>#blk-<bid>`，且 `mdparse` 不记录源码行号、`merge_title_pages` 合并前置页会重编 `B01..Bnn`。
2. **运行态与启动器耦合**：`apps/demo/` 缺少 `--root`、运行态写在代码仓内、`apps/home/launcher.py` 与 `apps/ops/server.py` 各自维护一套拉起逻辑。
3. **跨页缺少双向承接与范围定界**：检索抽屉无法跳入对应章段精读；分层读划词与目录无法带 `scope.books` 反向检索，也未对 `mode=trace` 做只检索不自动扣费的落点承接。

## 2. 全局架构调整

1. **统一服务网桥 `src/bookcorpus/app_links.py`**：
   - 收口 `SERVICES`、端口探测、带 `fcntl.flock` 文件锁的按需拉起 `ensure()` 与环境/CLI URL 覆盖。
   - 提供白名单相对路径跳板 `resolve_go_redirect()`（`/go/<key>?to=...`），供 `apps/home/`、`apps/demo/` 与 `apps/reading/` 共用。
2. **检索运行态与 `--root` 解耦**：
   - `Layout` 增补 `work_reading`、`work_search` 及 `sessions` / `terms` / `answers` / `related` / `运行记录`。
   - `apps/demo/context.py` 与 `--root` 让 `apps/demo/server.py` 启动时只读写 `<root>/工作区/检索/`，移除 import 期环境变量剥离 hack；`trace.build` 与 `/api/run` 增加显式 `scope.books` 定界，`GET /api/books/meta` 提供书名元数据。
3. **分层读源码坐标与 `GET /open` 解析**：
   - `src/bookcorpus/reading/mdparse.py` 保留 front matter 与首个 H1 后的真实 1-based `start_line` / `end_line`；`Library.read_chapter()` 保留块来源 `source_file`（兼容 `merge_title_pages`），`Library.book()` 支持新入库单书增量刷新；`Store.append_op()` 补齐跨进程 `fcntl.flock`。
   - `src/bookcorpus/reading/locator.py` 与 `GET /open` 将 `(uid, path, line, q)` 解析为规范 `/chapter/<uid>/<nn>?...#blk-<bid>`（非章节路径退回 `/book/<uid>`，无正文退回友好 404）。
4. **前端联动与模块化**：
   - 将 `apps/reading/web/chapter.html` 内联脚本抽离为 `apps/reading/web/assets/chapter.js`，增加来路上下文条、持久 `.hit` 轮廓与 `<mark>` 句段高亮，以及 `#selection-bar` / 页头 / `book.html` / `catalog.html` 出站检索入口（默认 `mode=trace`）。
   - `apps/demo/web/session.js` 支持 `?q=&books=&mode=trace|prefill`，在 `#drawer`、`.ev`、`.book-pick` 增加分层读跳转；`apps/daily/` 通过 `chapter.path` 直达 `/open`（保持只读与零子进程）。
   - 清理 `src/bookcorpus/reading/__init__.py` 的 `TIER_KEYS`、`apps/reading/web/assets/app.css` 无用 `.depth-*` 样式及 `apps/home/web/index.html` 过时三档文案。
