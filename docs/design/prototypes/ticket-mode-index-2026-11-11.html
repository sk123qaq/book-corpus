分层读 · 读本工单

“本章读法”选择器 · 三个静态变体

同一份工单上下文，三种选择控件。默认都是“跟随本书（论证）”，模型建议“论证”，选别的模式会变成“本章覆写”，并可恢复跟随本书。左侧正文是占位样本，不是真实章节。

变体 A · 下拉

一个下拉，最省空间

工单里只有一行“本章读法”。选项收在 select 里，默认“跟随本书（论证）”。

  • 桌面/手机都最紧凑
  • 四种模式不展开看不到
  • 适合熟练用户、低频入口
打开变体 A →
变体 B · 多按钮

四种模式同屏

“跟随本书”一行，下面 2×2 分段按钮；建议项带角标，选中填充松绿。

  • 一屏看到全部选项
  • 手机仍可读，工单不算太长
  • 说明句最短，适合工单密度
打开变体 B →
变体 C · 卡片

每张卡带一句说明

2×2 单选卡，每张卡解释“这类书怎么读”；建议卡带角标和勾选。

  • 桌面最好读，解释最完整
  • 手机纵向太长，工单占满首屏
  • 适合首次选择、需要教育的场景
打开变体 C →

我的建议：B 做主方案；把 C 的说明句压成 B 按钮下的一行小字（或 title），A 作为窄屏降级。这样“模式全可见”和“工单不臃肿”能同时成立。
