流程 01 · 运行时主链

全链路：一句话怎么变成可核对的答案

输入一句中文问句（可带点名书与会话上下文）→输出{answer, recap, citations, confidence, not_found}，每条引文带 path/line/quote

01

切词

apps/demo/trace.py:294

把问句交给模型，输出 terms 与 groups（每个概念一组同义词）。缓存键含问句与 thinking 档；模型不可用时退到概念表包含匹配与问句切块。

决策

不自写中文分词：问句里的概念边界（“礼治/法治”）用 bigram 切不出来。切词每题只做一次，之后整条链路复用。

读数

命中缓存 0 次模型调用；未命中 1 次，结果不可用再试 1 次，之后降级。

terms + groups
02

五轮规划

src/bookcorpus/scripts/book_query.py:195

每轮换一种词集查段落，算覆盖、分差、全组三段；到线即停，最多 5 轮。输出 best round、书序、每本书的 3 章候选。演示页取前 8 本，CLI 默认 10 本。

决策

逐轮加词，而不是一次把全词 OR 出去：全词会把“礼”和“秩序”拆散；而删掉一个词几乎总能抬分，所以只在“到线”的轮次之间比较。

读数

45/60 题到线，均 1.40 轮，0 次 cap；检索 + 书级 + 选章 p95 650 ms。

候选书序
03

段落打分

src/bookcorpus/scripts/qsearch.py:107

FTS5 bigram MATCH 取池（2,000 段，正文 ≥40 字），按 rank_score = (-bm25 + 0.8×命中词数 + 0.15×log1p(len)) × 假名惩罚 排序；假名占比 >10% 乘 0.55。

决策

BM25 之外只加“命中词数”和“长度”，不加学习型特征：库内 300 万段，任何逐段模型调用都换不回时延。同义词命中也计数，所以词集较全的书略占便宜。

读数

组覆盖重排与纯 BM25 的 top-10 平均重叠 9.5/10，top1 改写 4/59；0.8×cov 中位 0.8、最大 2.4。

段落分
04

书级聚合

src/bookcorpus/scripts/book_score.py:161

按书聚合 best、support（≥0.75×best 的段数，封顶 5）、topk（最好 3 段均值）、coverage（去重命中组/总组），再算 0.60×best + 0.25×topk + 0.15×coverage + 0.05×log1p(support)。best≤0 的书直接丢。

决策

不用旧的 0.7×best + 0.3×mean：长书章多、段落多，会把单章书按全书均值拉低。书级只负责“捞书”，不负责“读哪章”。

读数

书级 hit@10 0.983（当前索引 mix 0.967）、书级 MRR 0.877；同分按路径稳定排序。

书序 + 分差
05

书名明确吗

判定src/bookcorpus/scripts/book_cards.py:193

精确点名、作者、原句、明确书名提示 → 不弹卡，直接进选章；同名歧义，或前二名分差 <10%、前 10 名出现 ≥3 种类型 / ≥50 章长书、概念题 → 弹 ≤6 张书卡。

决策

书卡不是检索收益，而是让用户纠正“问的是哪本”的产品入口。等宽复测卡片 top3 15/21、top6 17/21，与循环同宽读数相同。

读数

60 题里触发 21 次；卡片首章与循环首章一致；默认展示由产品定，不由指标定。

明确 · 不弹卡

成答

apps/demo/answer.py:1566

点名书 exact → 单书或“点名书 + 其余书”；sources ≥2 → 多书轮转；否则单书。单书 ≤5 窗 × 3,500 字、总 18,000；多书每本 ≤2 窗、点名书拿 50% 预算。pi 带只读 book_grep / read 补读。

窗口只带“证据起点”，不追求装下全部引文。28 份答卷里最佳章平均只覆盖 0.50 引文，另外 52% 由 agent 补读；工具是能力，不是强制步骤。

08

引文回查

apps/demo/answer.py:1370

服务端取每条引文的前 20 个非空白字，先窗口后整章逐行找；路径必须在 books/**.md 且属于本次 sources；行号以文件实际位置为准。找不到或重复的引文丢弃；0–1 条 → confidence=low 并注明“引文回查不足（n 条）”。

模型切词

流程 04 · 检索核心

五轮规划：什么时候停，停在哪一轮

01

分名词集

book_query.py:78 split_terms

从全词集里去掉 15 条动作词，得到名词集；名词集为空时退回全词集。名词集只用于“覆盖判据”和换词，不直接决定书序。

02

生成本轮词集

book_query.py:125 term_sets
  • R1 名词原词：最窄，先看核心概念落在哪。
  • R2 全词集：把定语、限定词加回来。
  • R3 名词 + 概念同义：只取概念表里的键与别名；resolve 精确相等，不做子串。
  • R4 全词 + 宽词：--broad，默认关。

决策

读数

概念表 127 条；R3 只有在表内命中键时才产生，不是每轮都多一次查询。

查这一轮

book_query.py:224 Planner._one

流程 05 · 打分

打分与聚合：段落分怎么变成书分

输入一轮的词集terms + groups→输出书序 BookScore[]

01

候选池

qsearch.py:125

para_fts MATCH expr，join para 取 path/book/line/text/chars；正文 chars ≥ 40；ORDER BY bm25 LIMIT 2000。exclude 词先剔除。

决策

池 2,000 不是拍脑袋：书级融合要看到同一本书的多段证据，池太小会截掉长书尾部；池太大则书级聚合变慢。BM25 排序保证池里先放“词面最像”的段。

读数

每段
02

命中词数

qsearch.py:135

cov = Σ(g in body for g in groups)：该段命中了多少个查询词（含同义词）。ASCII 组先 lower 一次；纯 CJK 查询不做大小写转换。

决策

这里数“词”不是“组”：同义词命中是独立证据，不应被去重。书级 coverage 才按组去重，避免同一概念多个写法重复加分。

读数

0.8×cov 中位 0.8、最大 2.4；与纯 BM25 的 top-10 平均重叠 9.5/10。

03

假名惩罚

qsearch.py:142

假名（U+3040–U+30FF）占比 >10% → penalty=0.55，否则 1.0；只压排名，不删除。

决策

日文原版、双语对照会挤进中文问句的 top；0.55 只压不删，留作对照，不把整本书从结果里抹掉。

04

段落分

qsearch.py:143

rank_score = (-bm25 + 0.8×cov + 0.15×log1p(len)) × penalty；按 (-score, path, line) 排序。--rerank 时加 rerank_bonus，默认关。

决策

rerank_bonus 默认关：它罚 #/**/|/> 开头与行号≤3，等于罚章首段；59 题 r@10 只从 0.267 到 0.283，MRR 0.166 不变，净收益 1 题。

读数

关掉后 top1 更偏向正文中段；章首段靠 BM25 与长度项自然进入，不靠特判。

同书所有命中段
05

书级四项

book_score.py:161 aggregate
  • best：该书最高段分；≤0 整本丢。
  • support：段分 ≥0.75×best 的段数，封顶 5。
  • topk：最好 min(3, support) 段的均值。
  • coverage：去重命中组数 / 总组数。
决策

support 封顶、topk 只取 3：再多段只说明“书长”，不说明“这本书更对”；封顶避免长书靠段数堆分。

读数

support 封顶 5；topk 的分母是 min(3, support)，单段书不会被 3 除。

加权
06

书分

0.60 / 0.25 / 0.15 / 0.05

score = 0.60×best + 0.25×topk + 0.15×coverage + 0.05×log1p(support)；并列按 (book, best_path, best_line) 排，保证可复现。

决策

权重来自 B1–B6 的 60 题 gold。对照方案里 mix=0.7best+0.3mean 会把单章书拉低，sum 让长书占位；best_support 用 capped support 换来更好的单章书与平均名次，hit@10 不降。

读数

hit@10 0.983（当前索引 mix 0.967、sum 0.883）；long_share@10 0.120（全库段数基线 0.2797）；书级 MRR 0.877。

书序
07

交给选章

rank() → list[BookScore]

书序按分数降序；每项带 best 段、章节数、类型、命中组、是否已有 prefix/queries 扩展。long_share 只用于读数，不参与书分。

决策

书级只回答“哪几本值得读”，不回答“读哪一章”。把两种判断分开，才能让书卡、选章、成答各自有可替换的默认值。

提示词

build_prompt / build_multi_prompt

单书 ≤26,000 字、多书 ≤30,000；开头 1–4 句结论，1–6 节；每个判断至少一处原文；citations ≤10；输出一行 JSON：{answer, recap[3], citations[{path,line,quote}], confidence, not_found}。
