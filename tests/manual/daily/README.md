# 书库日课人工验收

启动：`python3 apps/daily/server.py --port 8772 --root /home/colaqaq/书库`，打开 <http://127.0.0.1:8772>。

1. 首屏是最新一期 2026-11-06，右上角「第 004 期」；左页边是「11月 / 06 / 星期五 / 第八章」，竖细线把页边与正文分开。正文两端对齐，段间留白，没有首行缩进。
2. 点「目录」里的 11.04，URL 变成 `#2026-11-04`，标题换成阿Q那期；刷新后仍是 11.04，浏览器后退回到 11.05。
3. 桌面 1440 宽下，摘句左侧是一条 2px 红线，下面 mono 小字是「第八章 · 第 25 行」；页脚一行是 md 路径、字数、查证范围、联网次数。
4. 当前期在「目录」里有小红点；hover 别的行，标题轻微右移；按 Tab 能看到清晰的焦点框。页面没有大圆角卡片、阴影堆叠、渐变、emoji 或图标。
5. 窄到 900px 以下，页边折成正文上方一行，不出现横向滚动。用空目录另起一个实例能看到「还没有日课」，页面不弹 alert。
