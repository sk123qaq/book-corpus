# 4 套主题预设（按章轮换，同一章内自洽）

选主题的原则：**章节类型 → 主题**，轮着来，别 33 章一个样。
每套只规定"色彩 + 字体气质 + 图表风格"，版式与组件由 subagent 自己发挥。

---

## T1 战略档案（墨蓝 + 铜 + 米白）

适合：框架、竞争分析、行业结构类章节。

```css
:root{
  --ink:#0e1a2b;      /* 主文字 / 深底 */
  --ink-2:#23344a;    /* 次级标题 */
  --paper:#faf6ed;    /* 页面底 */
  --card:#ffffff;
  --accent:#8a4a12;   /* 浅底上的强调文字（够深，对比度够） */
  --accent-deco:#b06f2d; /* 只用于线条/边框/大标题 */
  --muted:#5b6472;
  --line:#d9cfbe;
}
```
- 字体：无衬线正文 16–17px / 行高 1.8；标题可用较重的字重 + 一点字距
- 图表：白底细边框卡片，铜色做分隔线；矩阵用表头浅米底
- 气质：档案馆、研究报告

## T2 现代研究（炭黑 + 暖灰 + 橙）

适合：成本、效率、数据与量化类章节。

```css
:root{
  --ink:#16181d;
  --ink-2:#2f333b;
  --paper:#f5f4f1;    /* 暖灰底 */
  --card:#ffffff;
  --accent:#b3400f;   /* 橙（深版，可当文字色） */
  --accent-deco:#e2703a;
  --muted:#5f6470;
  --line:#e2e0da;
}
```
- 字体：偏紧凑，数字可用等宽或 tabular-nums
- 图表：数据块、条形/占比条、指标卡；允许深色数据带
- 气质：咨询报告、仪表盘

## T3 知识手册（墨绿 + 象牙白 + 细线）

适合：方法、步骤、操作流程、清单型章节。

```css
:root{
  --ink:#14342b;
  --ink-2:#25503f;
  --paper:#fbf9f2;    /* 象牙白 */
  --card:#ffffff;
  --accent:#1d5c58;   /* 青绿（深，可当文字色） */
  --accent-deco:#8aa79b;
  --muted:#5c6b64;
  --line:#dfe5dd;
}
```
- 字体：正文 16.5px / 行高 1.85；小标题可用编号徽章
- 图表：编号步骤条、折叠清单、检查表；细线分隔
- 气质：操作手册、工具书

## T4 杂志专题（酒红 + 米白 + 大字号）

适合：案例、行业演变、故事性强的章节。

```css
:root{
  --ink:#1b1a19;
  --ink-2:#3a3532;
  --paper:#fdfaf6;
  --card:#ffffff;
  --accent:#7a1f2b;   /* 酒红（深，可当文字色） */
  --accent-deco:#b5453f;
  --muted:#6b6259;
  --line:#e8ded2;
}
```
- 字体：大标题（32–44px，可用衬线），导语 18px；正文 16.5px
- 图表：大图 + 图注、拉引金句、案例卡、双栏对照
- 气质：专题报道、深度文章

## 通用提醒（四套都适用）

1. **别在浅底上用浅色字**：给深色底准备的浅米/浅金色，落到白底卡片上会看不清。
   同一类名要在深浅两种底上通用时，用作用域限定（如 `.dark .x{…}`）。
2. 正文与背景的对比度：正文 ≥ 4.5:1，大标题 ≥ 3:1。深底区块用浅字，浅底区块用深字，两套颜色分开定义。
3. 深色区块（封面、结论区、数据带）是拉开层次最省力的手段，一章用 2–3 处即可，别满页深色。
4. 主题只是起点：同一个主题在不同章节，允许不同的区块布局与图表风格。
