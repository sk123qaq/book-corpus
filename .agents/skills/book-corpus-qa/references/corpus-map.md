# 书库结构地图

`$BOOKS_ROOT/books/**/md/` 是正文区。每本书一个目录，路径形如 `books/<uid>/md/`，由 epub 或 PDF 按目录拆章生成。扫描版 PDF 常常只有单文件。

`$BOOKS_ROOT` 指工作区根目录（有 `books.toml` 的那层）。没设这个变量时，先 `cd` 到工作区，或 `export BOOKS_ROOT=$PWD`。

本页只写结构约定与检查方法。具体数字随语料变化，用脚本现测，不要照抄别人的快照。

## 先测自己的语料

```bash
cd "$BOOKS_ROOT"
book-corpus stats
```

`corpus_stats.py` 只读 `library.db` 与 `books/`，报书目数、md 数、章节数、体积、未收录项、系列分布与重复片段。拆完一批 md 之后重跑一次，把输出当成本次的事实。

单次检索的耗时也现测：

```bash
time rg -l -g '*.md' '测试词' | wc -l
time grep -rl --include='*.md' '测试词' 库 | wc -l
```

## 每本书自带的元数据（先读它）

书目录下的 `README.md` 字段固定：`合集 / 作者 / 出版 / 日期 / 章节 / 图片 / 来源`，后接 `## 目录`（逐章链接）与 `## 未收录（卷首/卷尾页）`。

同一目录下的 `.manifest.json` 记转换工具版本、源文件 sha256、章数、审计比值与受理例外。章数或来源可疑时先读它。

- `合集` 字段有值时就是系列名。判断一本书属于哪个系列、有没有兄弟卷，看这里，别猜。
- 系列另有独立说明文件，放在 `$BOOKS_ROOT/tables/系列/<系列>-合集说明.md`。**卷序看这里，不要按目录名排序**，`ls` 出来的顺序通常不对。
- **`未收录` 是关键字段**。转换时可能丢弃扉页、版权页、目录页、序言、后记。名著的招牌论断常在自序里。遇到「库里翻遍了却没有」的现象，先回 README 确认该部分是否被收录。
- PDF 路线常常「按页全收」，这一栏会写 `无（文本层按页全收）` 或 `无（扫描书按页全收）`。看到这种写法就知道扉页、版权页、目录页都在正文里。

## 章节文件命名

`NN_标题.md`，NN 是连续文件序号。

- **排序只认 `NN_` 前缀。** 文件名里的「第X章」会按部重号，例如 `02_第一部事实.md`、`03_第二章某旅馆.md` 混排。
- 命名风格不统一：语义标题（`01_序章.md`）、章号加标题（`03_第九章…`）、四位数序号（`0003_第一章…`）。
- 脚注常独立成文件（`05_脚注.md`）。术语表和生僻概念解释先查它。
- **开场垃圾与前置页**：盗版电子书会插入 `0001_制作说明.md`、`0002_…精品书生产者.md`。扫描书的肖像页、出版说明占前几章，小说的各国版本自序也占前几章。顺序读之前先扫一遍文件名。
- **文件名 ≠ 内容**：有的书是「奇数号是章标题文件、偶数号才是正文」交错；有的书每章都有一个同名 `结语.md`，引用必须带章号路径。

## 系列与超长书

- 系列卷序看 `tables/系列/`，不要按目录名排序。
- 超长书（千章级）先测章数与正文体积：

  ```bash
  BOOKDIR=$(book-corpus run lq "SELECT 'books/'||path||'/md' FROM book WHERE title='书名'")
  find "$BOOKDIR" -name '*.md' ! -name README.md | wc -l
  du -sh "$BOOKDIR"
  ```

  然后靠章节标题里的实名、地点、事件收窄，再 grep。单文件巨章（一章几百 KB、没有二级标题）是隐形陷阱，文件名帮不上忙，只能靠锚点字符串定位。

## 文本特征

- **引号混用**：同一本书里 ASCII `"` 与中文 `“”` 并存。锚点只用汉字串，不要带引号。
- **一段=一行**：论说文与部分小说按段落排版，单行可达数千字。行号粒度 = 段。
- 少数字按自然段保留换行，行号密度低。
- OCR 与录入噪声：多余字母结尾、英文短语粘连、人名错字。**引文照原文逐字抄，不改错**，可以在旁边注明疑似错字。

## 别名与称谓（会直接废掉检索）

同一人物常有本名、别称、英文名、第一人称四种写法，命中量级可能差几个数量级。聚合型问题开工前先做别名量级比对：

```bash
for w in 本名 别称1 别称2; do
  printf "%s=%s\n" "$w" "$(grep -ro "$w" "$SERIES"/*/md | wc -l)"
done
```

结论：**先用最短核心字试水，再看命中量级**。量级异常（0 或个位数）就先换词，不要断言"书里没有"。聚合型问题（人物经历、关系线）本质上是顺序阅读题，检索只能用来划边界。第一人称「我」承载主要叙事时不可检索，这类问题以按 `NN_` 前缀顺序推进为主。

## 拆书残留：同一段文字出现在多处

引用时固定到一处并说明，否则行号会打架。常见形态：

- 章标题文件与正文小节文件内容完全相同。
- 分卷汇总文件与各篇文件重叠。
- 同一部书的两个版本各存一份，标点与数字格式略有差异。
- 拆章时同一段被复制到相邻章。

检测：

```bash
book-corpus run md_review_report --uid <uid>
```

报告里的「跨文件重复片段」就是这一类。

## 重复书目

同名不同译本常以「（2）」后缀并存。不同译本的译名不同，引用前先确认用哪一版，并在报告里说明。不要在两版之间来回引用。

## 原文自相矛盾（照录，不调和）

同一本书里出现两个数字、两个编号或两种说法时，**并列报告并给出各自出处**，不要替作者选一个。常见于数字（人数、颗数）、章节编号、人物自述次数与正文叙述不一致。

遇到这类冲突，先确认不是 OCR 错字，再按原文并列。
